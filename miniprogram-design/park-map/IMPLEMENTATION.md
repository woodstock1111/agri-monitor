## 地图页（pages/parkmap）

- 不用 canvas：开发者工具里 canvas 永远盖在其它视图之上，改样式还会被重建。地图是 `movable-area` / `movable-view` 里的一张图片，拖动和惯性由微信原生处理。
- 业务地块按编号 1→20（自上而下）占位。地块上是两行标签（名称、品种），屏幕中心所在的地块显示荧光高光并同步到底部卡片；停稳后离中心近的自动居中。点地块进入详情。
- 未解锁区域：已解锁地块周围是一块椭圆形空地（每块地的轮廓都在椭圆 80% 以内，雾从 86% 才开始），中线以下整片盖着半透明的雾，边缘一圈云朵（同一张贴图）。上方不盖雾。
- 拖动范围只到“每块已解锁地块都能居中”为止（`movable-view` 只有这么大，画面按偏移放在里面），不会拖进雾里。
- 本机记住已解锁的空位（`agri_park_fog_v1`）。下次进入时有新地块：先按旧范围盖雾，约 1.3 秒后新旧两层雾交叉淡入淡出，镜头对准新地块；地块减少则雾跟着收回。
- 进入地图时，纸色底先淡掉，三团云向两边拨开（只用位移和透明度过渡）。
- 顶栏、地图、底部卡片上下排开，互不重叠；智能管家、问小薯、成熟度、收成预测、地块详情都用同一个底部抽屉。
