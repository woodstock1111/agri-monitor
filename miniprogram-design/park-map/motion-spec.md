# 产业园地图 · 动效设计与逐帧分镜

暂定 v1 · 2026-09-29 · 状态：待功能完成后制作动效样例，当前为设计时序。

配套：[实施 Plan](PLAN.md)、[界面设计稿](design-spec.md)。下述时长和幅度用于首轮样例；必须真机调整。网络时间不计入纯动画时长。

## 1. 动效语言

画面像一张随手移动的田园画；相机轻移，选中线自然浮现，信息紧凑换入。保持地块形状、水路和位置稳定，让用户理解自己从哪里来到哪里。

| 类型 | 初值 | 用途 |
|---|---|---|
| 触控即时反馈 | 80–120 ms | 按钮按压、可点击反馈 |
| 轮廓/文字更新 | 160–220 ms | 选中线、文字淡入淡出 |
| 短定位 | 280–360 ms | 相邻地块相机平移 |
| 园区/详情过渡 | 320–420 ms | 上下文变化与抽屉衔接 |
| 首次园区入场 | 380–450 ms | 画面与固定 UI 同时入场 |
| 标准曲线 | `cubic-bezier(.4,0,.2,1)` | UI 状态变化 |
| 相机收束曲线 | `cubic-bezier(.22,1,.36,1)` | 定位、边缘归位 |

拖动过程不套缓动，位移和手指保持 1:1。不做每块田随拖动起伏，不做河流持续闪光。动画通常并行，不叠加成几秒的等待。触感只在成功切换或创建完成时轻触一次，可关闭；拖动和每帧预选不触发震动。

## 3. M01：进入园区

区分“进入园区”和“进入地块”：前者打开地图，后者打开地块详情。

| 时间 | 分镜 |
|---|---|
| 数据准备 | 封面点击后立即响应。目标数据可预加载；未就绪则展示田园底和加载提示，不播放假入场 |
| 0 ms | 正确园区画面已准备，相机处于最终视野的 1.03 倍；固定 UI 可见度为 0 |
| 0–280 ms | 画面渐显、相机缓慢回到 1.00 倍 |
| 60–340 ms | 标题渐显；底部从下方最多 8 px 换入，逐渐可读 |
| 380–450 ms | 相机收稳，正常交互 |

普通再次进入恢复该园区上次视野，不每次重播长入场。封面“查看某地块”带焦点参数时，先定位正确地块；若该入口语义要求直接看详情，则在数据就绪后衔接 M08，不依赖固定 360 ms 定时器猜测页面是否准备好。

跨页面能否与原生导航同步须在样例验证；默认只承诺目标页内部可控入场，不依赖未经验证的跨页面共享元素能力。

## 4. M02：产业园切换

```text
原园区完整显示 → 选择目标园区 → 等待目标数据
        → 旧画淡出 → 一次替换上下文 → 新画淡入 → 恢复浏览
```

| 时间 | 分镜 |
|---|---|
| 请求阶段 | 列表显示目标项加载；旧地图和旧标题保持一致，可取消或改选 |
| 0–140 ms | 目标数据就绪，选择抽屉关闭；旧地图降低可见度 |
| 140–180 ms | 以暖纸色/静态画面过渡底遮住切换点，原子替换园区、地块、视野、边界与信息 |
| 180–380 ms | 新画渐显，必要时做最多 2% 的轻靠稳；标题与底部同步换入 |
| ≤420 ms | 恢复输入，新园区位置和选中项稳定 |

园区之间不假装在同一地理空间中长距离飞行。无缓存首次选中以适合视野显示；有有效缓存则恢复。旧园区视野、选中项按园区分别保存。

快速改选采用最新目标；旧请求和旧动画回调失效。数据失败不启动换画，保留原园区并支持重试。过渡中短暂限制地图点击，不能把旧画面上的点击解释成新园区地块。切换结束必须重置 WXS 的相机与边界缓存。

## 5. M03/M04：上方拖动与松手

### 手势开始

- 在地图区域触摸后约 8 px 移动确认拖动，阈值按真机调节。
- 未达到阈值的短触按点击处理；达到阈值后抑制本次点击事件。
- 接手时取消正在运行的相机动画，读取已显示位置，避免跳回动画起点。
- 地图支持横、竖、斜向平移；在顶部、底部和抽屉开始的触摸不进入地图手势。

### 拖动中

世界容器整体平移；地块大小不变。近中心候选可以轻强调，但不会每跨过一块就改写业务选中项。可见区域进入新的分块时批量刷新；提前准备缓冲，防止快速拖动出现空洞。

### 松手

1. 根据释放速度给予短惯性，距离与时长有上限；到边界时平滑减速。
2. 超出边界的视觉回弹最多约 12–20 px，收束 180–240 ms，不做大弹簧。
3. 候选地块距离焦点锚点很近时，轻吸附最多约 24–40 px，提交选中项并同步底部。
4. 没有近邻候选时停在用户选择的视野，保留原选中信息；不强行把远处地块拉回中央。

惯性与吸附合并成一次收束，避免先停下再突然第二次移动。相邻候选竞争时使用稳定距离/ID 规则，避免边界抖动。若选中项不在视野内，可在底部提供轻量“定位”操作；不持续用远处大箭头干扰绘画。

## 6. M05：底部切换地块

选择行是独立横向手势区，底部功能导航不响应切地块手势。

- 水平意图需明显大于垂直，首轮比例约 1.4；未确认前不吞掉其他合法操作。
- 左滑切下一块，右滑切上一块；距离约 36 px 或短快速甩动达到阈值时提交。
- 每次手势最多切一个；轻滑未达到阈值时信息回位，地图和选中项不变。
- 首尾不循环。边界最多给约 8 px 的弱回位反馈；箭头同时置为禁用。
- 箭头点击和全部地块列表选中调用同一切换逻辑，排序固定且可解释。

| 时间 | 分镜 |
|---|---|
| 手势跟随 | 行内文字最多随手指偏移约 16–20 px；整张底面不移动 |
| 0 ms（提交） | 锁定目标地块与目标相机；旧信息开始淡出 |
| 0–160 ms | 旧文字向滑动方向退出 12–16 px，新文字从反方向小幅进入 |
| 0–320 ms | 地图平移到目标锚点；旧轮廓变淡，新轮廓逐渐出现 |
| 320–360 ms | 相机收稳，目标文字与边线达到最终状态 |

目标 ID 在提交时一次更新，地图轮廓与底部始终对应同一个逻辑目标。动画中允许继续切换，最新目标接管，不把 10 次操作排成 10 段等待。此时点击“进入”应打开当前显示目标，不能打开还未退出的旧地块。

邻地距离很远或来自搜索时，按 M10 用短淡换定位；不让用户看到地图高速飞越一百块田。

## 7. M06：地图点击

第一次点未选地块：选中线在 160–220 ms 内换入，底部信息同步；若地块已充分可见则保持镜头。被顶部/底部压住时才短距离移到安全焦点。

再次点已选地块或点底部“进入”触发 M08。首轮样例验证这一交互是否清楚，可通过首次轻提示“点击地块选择，再次点击进入”帮助理解。自由拖动永不自动进入详情。

命中区使用稳定地块形状/扩展点击区；标签点击等同地块点击。相机动画中需用当前变换做坐标转换，不能使用动画终点转换点击。

## 8. M07：新建成功

创建流程不是动画计时器：表单校验和业务请求完成后才触发。

| 时间 | 分镜 |
|---|---|
| 表单阶段 | 明确显示当前园区，防重复提交；新位置可保留内部预留，不显示正式地块 |
| 0 ms（成功） | 正式 ID 与布局坐标确认；准备新位置周围的田埂、地块和背景 |
| 0–220 ms | 表单退出；若新增在视野外，镜头开始平移 |
| 100–340 ms | 新地块由浅底渐显、缩放 0.97→1.00；田埂轮廓同步出现，不从屏幕天降 |
| 160–400 ms | 底部名称换入，选中线出现；已有地块保持原位 |
| ≤450 ms | 完成一次轻触感与简短成功提示，停在新地块 |

新增在当前视野内时省略大平移；在远处时先短淡换定位，再显现。由服务器或多人操作新增的地块不强行夺走当前镜头：刷新数量与可见区域，提供“查看新增”入口。

创建失败保留表单输入，不播放落位；请求结果不明确时先核对提交结果再重试。取消后清理预留位置，不能留下虚假正式地块。创建提交期间禁止切换所属园区，或明确先取消创建；所属上下文不可偷偷改变。

## 9. M08/M09：进入地块与返回

### 进入

| 时间 | 分镜 |
|---|---|
| 请求阶段 | 立即反馈进入按钮，预取/加载详情；失败仍留地图，不展示空内容冒充详情 |
| 0 ms（就绪） | 保存精确相机、选中项与园区；计算详情上方仍可见的地块锚点 |
| 0–280 ms | 相机轻靠近，缩放为进入前的约 1.12–1.18 倍，目标地块移到上方可见区 |
| 40–220 ms | 原选择行渐退；底部导航按抽屉状态隐藏/遮挡 |
| 80–380 ms | 单一详情抽屉从下方进入，内容同步渐显 |
| ≤420 ms | 详情操作可用；地图背景保持安静 |

详情占高遵循最终功能页，不为了露出地图压缩核心业务内容。如果原生抽屉提供自己的动画，应协调其时长，不能再外套第二次上滑。需验证其遮罩/地图可见范围，不能承诺未验证的原生动画改造。

### 返回

详情抽屉退出与相机恢复并行，总时长约 280–360 ms；底部选择行回到原位。恢复进入前的精确坐标和缩放，避免每次返回都跳回首块田。系统返回、手势关闭与页面返回共用同一个清理流程。

若期间地块被删除或权限失效，恢复有效园区视野并清除无效选中项，不复活旧数据。

## 10. 取消、竞争与生命周期

| 当前情况 | 新操作 | 处理 |
|---|---|---|
| 惯性/定位中 | 新的地图拖动 | 从当前画面接手，取消旧目标 |
| 地块切换中 | 再切一块 | 更新最新目标，不排队 |
| 地块切换中 | 进入 | 进入当前已提交目标，终止无关定位 |
| 园区请求中 | 改选园区 | 旧请求失效，保留原画，加载新目标 |
| 园区换画中 | 地图点击 | 短暂拦截，避免坐标/身份混用 |
| 新建提交中 | 退出/切园区 | 按业务规则取消或保留明确的提交状态，不重复创建 |
| 详情加载中 | 切换地块/园区 | 旧详情响应失效，不弹出旧详情 |
| 任意动画 | 页面隐藏/卸载 | 停动画、清回调；保存已提交有效状态 |

相机使用统一控制器，动画附带代次/取消标记；完成回调必须校验上下文。JS 与 WXS 的相机状态要有明确同步点，尤其是园区切换、新建定位和详情返回，不能保留 WXS 的一次性初始化旧值。

## 11. 减少动画与性能降级

提供应用内“减少动画”设置；系统是否有可用的减少动态效果信号须实施时核查，不能将无障碍启用等同于减少动画偏好。

| 正常效果 | 减少动画/低性能版本 |
|---|---|
| 地块定位平移 | 直接定位＋约 100–160 ms 淡换 |
| 园区交替与轻缩放 | 去缩放，约 120–180 ms 淡换 |
| 入场靠稳 | 静态最终视野，固定 UI 简短渐显 |
| 详情相机靠近 | 保持相机，仅使用必要的抽屉/内容过渡 |
| 新建轻显现 | 直接落位，高亮轮廓和成功提示 |
| 松手惯性与回弹 | 去惯性、立即限制到合法边界 |

任何降级都保留即时手势反馈、目标高亮与信息同步。不会为了省帧使按钮点击无响应。关闭触感、减少动画与画面性能降级分别管理。
