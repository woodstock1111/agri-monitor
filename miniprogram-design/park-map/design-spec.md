# 产业园地图 · 界面设计稿与布局规范

暂定 v1 · 2026-09-29 · 配合 [实施 Plan](PLAN.md) 与 [动效规范](motion-spec.md) 使用。

## 1. 视觉基准

![已暂定的艺术地图与紧凑底部](assets/approved-direction-v1.png)

采用平面绘画感的田园地图。地块是沿田埂拼接的彩色土地，水系和植被贯穿其中。画面的特别之处来自形状、颜色、笔触与疏密关系；控件保持清楚、克制。

原图属于美术参考，实际屏幕中的安全区、胶囊、文字字号和点击区按以下规范重新排版。图中文字须重新作为真实 UI 绘制。以下尺寸按逻辑 px 描述，以 390 px 宽屏为标准稿；适配时不能将所有尺寸无条件等比例放大。

## 2. 页面分层设计稿

```text
┌──────────────────────────────┐
│ 状态栏安全区      微信胶囊     │  A 固定顶部
│ 地瓜产业园 ⌄                 │    园区选择
│ 海南 · 文昌    12块   ＋新建   │    地区 / 全部地块 / 创建
├ · · 顶部暖纸色逐渐融入画面 · · ┤
│     田地      水系      植物   │
│          东002                │  B 可拖动世界
│   西001     ╔ 东001 ╗         │    地块边界随画面移动
│             ╚══════╝    田地  │    选中线与底部信息同步
│      田埂            东003    │
│   · · 图像自然延伸到四边 · ·   │
├ · · 画面轻柔过渡至暖色托底 · · ┤
│ ‹  东001  高系14 · 130亩  › 进入↗│ C 固定底部，共用底面
│ ──────────────────────────── │    紧凑选择行
│  智能管家    问小薯    成熟度  │    现有功能入口
│          底部安全区           │
└──────────────────────────────┘
```

示意不代表控件的最终像素位置。地图覆盖整个屏幕；A/C 是叠加其上的固定 UI，世界拖动不会带动它们。顶部和底部允许遮挡部分地图，但选中地块定位目标处于两者之间。

### A：顶部园区区

| 元素 | 建议尺寸/行为 |
|---|---|
| 顶部安全区 | 读取实际系统及微信胶囊尺寸，不能写死 iPhone 数值 |
| 左右内容边距 | 16 px；地图背景仍铺满宽度 |
| 园区标题 | 22–24 px，中等字重；名称＋小下拉箭头构成完整点击区 |
| 标题可用宽度 | 避让胶囊；长名称单行省略，选择面板显示全名 |
| 副行 | 12–13 px，地区与数量；“12 块地块”可打开全部地块列表 |
| 新建按钮 | 文字 13–14 px、细边框、轻圆角；视觉约 30–32 px 高，点击区至少 44 px |
| 背景 | 暖纸色向透明渐变，不用一条硬线割断地图 |

只有一个园区时隐藏下拉箭头和切换交互；多园区时点标题打开统一的园区选择抽屉。返回封面采用小返回入口并避让标题/胶囊；最终排列与功能完成后的导航结构核对。

### B：可拖动画布

- 常态单个地块可见宽度约 80–130 px，形状有变化，避免统一卡片阵列。
- 选中地块与同类邻地大小接近；高亮通过轮廓和微弱亮度实现，不长期放大到挡住邻地。
- 普通边界由约 3–5 px 的浅暖田埂和约 1 px 的深绿轮廓组成，远处可简化为一条。
- 选中边界采用内外两道细线，主线约 2 px，辅线约 1 px，间距约 2 px；不使用发光霓虹。
- 名称保持水平、12–13 px、深绿色；必要时使用一层轻薄纸色衬底，不能直接写入田地纹理。
- 植物优先沿田埂、河岸、转角分布，水系保持连通感；两者不挤占可读边界。
- 普通地块只显示名字；品种、面积和其他信息由底部或详情承接。
- 控制标签密度并避让。视觉不规则形状与真实命中区分开，点击边缘采用最近地块规则；存在歧义时不直接进入详情。

### C：统一底部托底

底部由一张薄雾面暖纸色表面承接，顶部用约 24–40 px 渐变柔化。选择行和功能入口不各自套一个玻璃胶囊。背景延续画面的暖色、微粒感和绿灰描边。

| 元素 | 建议尺寸/行为 |
|---|---|
| 地块选择行 | 主内容约 56–64 px 高；首版优先保持单行紧凑 |
| 左右箭头 | 小线性图标，分别至少 44×44 px 点击区 |
| 地块名 | 16–17 px，中等字重，单行；无“当前地块”大标题 |
| 品种/面积 | 12–13 px；示例“高系14 · 130亩”，缺失数据显示“—” |
| 进入 | 13–14 px，小型细框按钮，点击区至少 44 px 高 |
| 分隔线 | 1 px、低对比、左右内缩 16 px |
| 功能导航 | 三等分，图标约 20–22 px，文字 11–12 px；一项至少 44 px 高 |
| 安全区 | 独立追加，底色连续，点击区不落入手势指示条 |

宽度紧张时先缩短品种/面积展示，再把元信息移到名称下方，选择行可增高至约 72 px。箭头与进入按钮不缩小点击区。示例“东001”改名后即使很长，也不能推动右侧按钮溢出。

首/末地块对应箭头禁用；不从最后一块瞬间跳回第一块。左右滑动的相邻信息在本行内部裁剪和渐隐，不在屏幕两侧露出邻卡。地块多时可通过顶部全部地块列表直接跳转。

## 3. 配色、材质与图标

以下色值是从参考方向提炼的设计 token 初值，后续静态定稿时微调。

| Token | 初值 | 用途 |
|---|---|---|
| `park-paper` | `#F2EFDE` | 顶部、底部、田埂暖底 |
| `park-ink` | `#354B3D` | 主文字、线性图标 |
| `park-ink-muted` | `#687568` | 辅助信息 |
| `park-sage` | `#A9B893` | 主要绿色田地 |
| `park-olive` | `#7F9270` | 深色地块与植物 |
| `park-water` | `#75AAA4` | 水系与少量碧色田地 |
| `park-ochre` | `#C5AD73` | 黄色田地 |
| `park-clay` | `#B68169` | 少量陶土色块 |
| `park-selected` | `#526F54` | 选中边线 |

地块色由稳定样式种子决定，不能每次进入随机变化。警告、权限与异常提示沿用业务语义，并保证文字/图标足以区分状态，不只依赖颜色。

UI 使用系统中文字体；艺术性主要来自地图，保证标题和信息可读。图标采用统一粗细的简洁线条，与选中边线呼应。纸纹在 UI 区极轻、静态；无需实时噪声或重玻璃反射。文字对比在合成后的背景上验收，普通文字目标达到 4.5:1。

## 4. 园区与地块选择面板

### 园区选择

使用与页面同色系的暖雾面底部抽屉：标题“选择产业园”、当前项勾选、园区名称和地区两行。较多时可搜索，列表自身纵向滚动。关闭操作及系统返回可取消。选择成功后关闭抽屉并播放园区过渡；失败保留可重试提示，不把标题先改成未加载成功的园区。

### 全部地块

使用同一抽屉容器，显示搜索框和紧凑地块列表。稳定排序由业务确定，默认保持名称/明确排序键，不随镜头位置变动。列表选择后关闭、更新底部并移动相机。与园区面板、详情、新建表单互斥。

## 5. 新建地块设计

```text
点顶部“＋新建地块”
       ↓
暖色表单抽屉：所属园区（明确显示）＋业务必填字段
       ↓ 提交成功
抽屉收起 → 外围可用位置显现 → 镜头移到新地块
       ↓
选中轮廓＋底部名称更新 → 用户可继续“进入”
```

默认不要求用户在艺术地图上准确选点。位置由稳定布局算法安排，必要时表单给一幅小位置预览。若将来允许指定位置，再单独设计放置模式。

视野内新增时，保留相机或只做短距离微移；视野外新增时，镜头沿平滑路径移到外围。途中要显示准备好的地图块。极远位置采用短淡出、定位、淡入，避免高速掠过整园。持续展示水系、田埂和背景，不通过大块空白暗示“未开发”。

提交中按钮显示进度并阻止重复提交，其他业务权限依功能规定。失败保留输入和明确原因；返回/取消不在地图留下半成品地块。

## 6. 数量、屏幕与状态设计

| 状态 | 地图 | 顶部/底部 |
|---|---|---|
| 空园区 | 小片田园背景与自然留空，清楚提示“还没有地块” | 新建可用时提供创建；隐藏地块选择/进入，保留业务导航 |
| 1 个地块 | 合理尺寸，周围补水系植物 | 箭头禁用，当前信息和进入可用 |
| 5–6 个 | 大部分可见，保持正常尺寸 | 紧凑选择行，轻松浏览 |
| 12–30 个 | 连续世界，常见视野显示局部 | 全部地块列表可直接定位 |
| 100/300 个 | 分区裁剪，稀疏标签，保持局部清楚 | 搜索/列表是快速定位入口 |
| 首次加载 | 纸色/田园底先出现，不填虚假数量 | 简洁加载提示，真实数据就绪后入场 |
| 切换加载 | 原园区完整保留，显示目标加载状态 | 禁止进入混合数据；可取消/选择其他园区 |
| 请求失败 | 保留已加载地图；首次失败给重试 | 简洁错误文本，不显示假设备数值 |
| 被删地块 | 移除选中轮廓，选择有效邻项或无选中 | 取消其详情请求，提示“地块已不存在” |

地图相机的目标锚点位于顶部内容底缘与底部渐变顶缘之间的可用区域中心偏上约 5%。屏幕矮时优先收紧装饰与 UI 间距；不会将选中地块塞到托底下面。

## 7. 后续正式设计稿清单

本次以暂定参考图、上述结构和尺寸作为设计依据。P1 阶段应输出以下标注稿；P2 阶段才制作可交互动效样例。

- 390 px 默认页面、小屏 320 px 页面与长名称适配。
- 5 地块、30 地块与空园区三种布局。
- 园区选择、全部地块、新建表单与提交状态。
- 新建地块“原视野—外围新增—定位完成”三联稿。
- 进入详情“选中—靠近—详情打开”与返回稿。
- 错误、弱网、游客权限、减少动画版本。

正式稿不能只画一个顺利状态。上述状态按 [Plan 验收矩阵](PLAN.md#9-验收矩阵) 与功能结果逐项落地。
